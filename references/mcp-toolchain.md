# mcd-mcp 工具链速查 · 麦麦家长助手

## 1. 调用链总览

```
query-nearby-stores   → 确定门店（storeCode / beCode）
query-meals           → 拉取当前门店可售菜单（name + currentPrice）
query-meal-detail     → 拆套餐组件（rounds，默认取 isDefault=1 的 choice）
list-nutrition-foods  → 单品营养数据（能量/蛋白质/脂肪/碳水/钠/钙）
query-store-coupons   → 该门店可用优惠券
calculate-price       → 叠加优惠券算实付价（只算价，不下单）
```

## 2. beType / orderType / beCode 传参矩阵

| 场景 | beType | orderType | beCode |
|---|---|---|---|
| 到店自取 | 1 | 1 | 不传 |
| 得来速（车道取餐） | 5 | 1 | **必传**（来自 query-nearby-stores） |
| 麦乐送（外送） | 2 | 2 | 必传（来自 delivery-query-stores） |
| 企业团餐 | 6 | 2 | 必传 |

- `query-nearby-stores` 需要 `beType`（1 或 5）+ `searchType`（1=收藏餐厅，2=按位置搜索，此时 city + keyword 必填）。
- `query-meals` / `query-meal-detail` / `query-store-coupons` / `calculate-price` 均需要 `storeCode`。
- 预约场景传 `reservationDate`（格式 `yyyy-MM-dd HH:mm`），非预约场景不传。

## 3. 价格单位（易错点）

| 工具 | 价格字段 | 单位 | 处理 |
|---|---|---|---|
| query-meals | currentPrice / originalPrice | **元**（如 "23.5"） | 直接用，**不要**除以 100 |
| calculate-price | price / originalPrice / discount / productPrice 等全部字段 | **分**（如 2350） | 展示时 ÷100 转元 |

历史踩坑记录：开发文档曾笼统写「价格单位是分」，实测 query-meals 返回的是元（三件套 33.5 元）。凡涉价格展示，先确认数据来源工具再换算。

## 4. 禁用工具（真实消费动作）

`create-order`、`party-order-create`、`mall-create-order`、`draw-lottery`、`auto-bind-coupons`、`cancel-order` 等一切会真实扣款/抽奖/变更账户状态的工具。演示与推荐场景只到 `calculate-price` 为止。

## 5. 特调（modification）传参规则

`calculate-price` 带特制选项时：
- 选中的特调项：`key` 取 query-meal-detail 返回的 `selectedKey`。
- 未选中但存在 `unselectedKey` 的特调项：`key` 取 `unselectedKey`，**也必须传入**。
- 即：含 unselectedKey 的特调组，组内所有项都要传。
- 特调组 minValues=1、maxValues=1 且只有 1 个 value 时，该项必选，不得向用户提供「不选」。

## 6. 菜单名 ↔ 营养库名匹配陷阱

`list-nutrition-foods` 的 productName 与 `query-meals` 的餐品名经常不一致。**禁止静默猜测**，按以下别名表取默认值并在输出中标注「（按 XX 计）」；无法匹配的明确告知无数据。

| 菜单名 | 营养库默认对应 | 说明 |
|---|---|---|
| 薯条 | 中薯条 | 也可能是大/小/迷你，需向用户确认 |
| 玉米杯 | 大杯玉米杯 | 营养库另有「小杯玉米杯」 |
| 派 | 菠萝派 | 营养库另有「香芋派」 |
| 新地 | 朱古力新地 | 营养库另有「草莓新地」 |
| 麦乐鸡 / 麦乐鸡块 | 麦乐鸡4块 | 营养库另有「麦乐鸡5块」 |
| 纯牛奶 / 牛奶 / 纯牛奶(盒装) | 纯牛奶（盒装） | 麦咖啡「牛奶」按杯型另有热/冰牛奶系列 |
| 可乐 / 雪碧 / 怡泉+C / 阳光柠檬红茶 | 对应「中杯」 | 营养库按杯型分开 |
| 麦咖啡美式 / 美式 / 卡布奇诺 / 奶铁 / 麦咖啡奶铁 / 燕麦奶铁 | 对应「中杯」 | 冰/热、杯型需确认 |
| 鲜萃咖啡 | 大杯鲜萃咖啡 | 营养库另有「小杯鲜萃咖啡」 |
| 麦辣鸡翅 | 麦辣鸡翅-2块 | 按 2 块装计 |
| 100% 苹果汁(盒装) | 100%苹果汁 | 括号全角/半角差异 |
| 【美汁源】黄金橙橙 | 【美汁源】“黄金橙橙” | 引号差异 |
| 那么大鸡排（椒盐风味） | 那么大鸡排 | 风味后缀差异 |
| 麦麦脆汁鸡1块 | 麦麦脆汁鸡-带骨里脊 | 琵琶腿为另一 SKU |
| 苹果片一袋(60g) / 苹果片一袋（60g） | 苹果片 | 开心乐园餐 round 里带规格后缀 |
| 麦乐鸡-4块 | 麦乐鸡4块 | 套餐组件名带连字符，营养库无连字符 |
| 鱼排堡 / 儿童鱼排堡 | 儿童鱼排堡 | 仅限开心乐园餐内的儿童规格，非「深海鳕鱼堡」 |

**匹配规则（脚本已固化）**：精确匹配 → 别名表 → 报告「无数据」。**刻意不做模糊匹配**——曾出现「龙焰鸡腿堡」被模糊匹配到「板烧鸡腿堡」的事故，静默错数据是儿童营养工具最危险的失败模式。遇到未知名，明确告知无数据，或人工确认后补进别名表。

其他已知缺口（截至 2026-10-18 该门店）：龙焰鸡腿堡系列、蘸酱炸鸡系列、部分新雪冰、蓝莓爆爆珠麦旋风、泷盐星星麦旋风、灰焰圆筒、奶香大米派、马苏里拉芝士条、月下相思扭扭薯等新品**暂无营养数据**——明确告知，不编数。

## 7. 套餐 rounds 解析要点

- 每个 round 是一个选配轮次；默认搭配 = `choices` 中 `isDefault: 1` 的项。
- 注意数据异常：曾出现 choice 级 `quantity` 与 `isDefault` 冲突（如汉堡开心乐园餐小食轮次：苹果片 isDefault=1 但 quantity=0，小杯玉米杯 isDefault=0 但 quantity=1）。**以 isDefault=1 为准，并在输出中说明另一选项的营养差异**。
- 玩具轮次（如「海绵宝宝×航海王系列玩具」）营养计 0，但计入开心度。
- 开心乐园餐 typically = 主食 + 小薯条 + 小食 + 饮料 + 玩具，整组按儿童份量设计。

## 8. 真实演练记录 A（2026-10-18 · 深圳南山）

**优惠券**：`query-store-coupons` 返回空数组 → 该门店当前无可用券，实付价 = 原价。

|---|---|---|---|---|---|
